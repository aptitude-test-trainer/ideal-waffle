# Aptitude Trainer

Free practice for skilled-trades apprenticeship aptitude tests:

- **GAN battery** (IBEW Local 134): paper folding and mechanical comprehension, in Randomized, Study guide, Practice and Meltdown modes, with animated replays when you miss.
- **ETA Algebra & Functions** (IBEW Local 701): 33 questions in 46 minutes, randomized or from the practice tests.

Open `index.html` in any browser, or use the live site.
