# Aptitude Trainer: notes for Claude

A practice website for skilled-trades apprenticeship aptitude tests (IBEW Local 134 = GAN battery: paper folding + mechanical comprehension; IBEW Local 701 = ETA test: Algebra & Functions, reading comprehension planned).
The owner builds it **one section at a time**: perfect a section, verify it, then move on. Never rewrite the whole site in one go.

## Layout

```
index.html        THE WEBSITE. Built file, served by GitHub Pages. Never edit by hand.
app/              Source of the site + build and check scripts
  shell.html      HTML + CSS (tabs, home screens, test screen, results)
  app.js          App logic: test flow, timers, practice mode, Meltdown, review, history
  gen.base.js     Question generators (paper folding engine, mechanical types, cube nets)
  nb1-nb3.js      Animation wrappers ("mv" groups) for mechanical types
  nb4.js          GAN study-guide data (SG_DATA) - GENERATED by pipeline/mk_sg2.py
  nb5.js          ANIM: animated walkthroughs (paper fold/punch/unfold, gears, generic mv scenes)
  nb6.js          ETA math generators (exact fractions, graphs)
  nb7.js          ETA study-guide data (SGETA) - GENERATED by pipeline/mk_nb7.py
  genbuild.py     gen.base.js + nb*.js (inserted at /*NEWTYPES*/) -> gen.js
  build.py        shell.html + gen.js + app.js -> app/local134-mech-set.html AND ../index.html
pipeline/         Turns the source PDFs/screenshots into nb4.js / nb7.js
sources/          Original study materials (PDFs, Bennett screenshot zip)
```

## Build

```
cd app && python3 genbuild.py && python3 build.py
```
Then commit `index.html` together with the source change. The site updates on push.

## Checks (run before every commit that touches questions)

```
cd app
node dump.js 300 && python3 verify.py        # every generated GAN question re-solved independently
node dumpmath.js 300 && python3 verify_math.py   # every ETA math item re-solved with Python fractions
node mvcheck.js .                             # animation wrappers must not change any question
python3 animall.py                            # every study-guide animation mounts without errors
python3 sgflow.py fold 390 && python3 sgflow.py mech 390 dark   # phone-width practice run, no sideways scroll, no JS errors
```
Playwright + Chromium are needed for the .py browser checks.

## Rules from the owner (must follow)

- **Study-guide answers come only from the source**: the PDF answer key, or the "Right answer:" line on the Bennett screenshot. Never substitute an answer from your own reasoning, even if you think the key is wrong. If an answer can't be found, tell the owner exactly which question.
  - Known: GAN SG mech #18 key says A; Bennett "cable strain" and "steel cable bridge" keys say B. Those three have no replay animation (a physical replay would contradict the key).
- Study-guide sections use **only** these sources: GAN HR Study Guide, GAN Practice Problems, Bennett test screenshots (GAN tab); Timed Simulations 1-4, Math Diagnostic, IBEW 33/34 tests (ETA tab).
- Independent verification is non-negotiable: every generated answer is re-solved by a separate checker before shipping.
- Mechanical and paper-folding questions contain no numbers or calculations.
- Fractions are shown stacked (numerator over denominator), never inline with a slash.
- Default timing: paper folding 24 Q / 15 min, mechanical 45 Q / 20 min, ETA Algebra & Functions 33 Q / 46 min.
- Must fit a phone screen: vertical scrolling only, no sideways scroll. Paper-folding diagrams stay light (test-like) in dark mode.
- Wrong answers in practice mode show a clean animated replay (paper unfolding, gears, moving parts).
- Wrong-answer choices should reflect real mistakes; keep the correct-letter distribution balanced.

## Pipeline notes

- `pipeline/mk_sg2.py` rebuilds `app/nb4.js` from `pipeline/nb4.orig.js` (GAN SG images), `gp/` (Practice Problems crops), `bt/` (Bennett: qs.json with answers read from screenshots, q/*.png crops, anim/*.svg replays), `gm/` (GAN mech replays), `pfq/` (paper-fold models for replays).
- `pipeline/mk_nb7.py` rebuilds `app/nb7.js` from `eta/crops.json` + `eta/ans_*.json` (verified keys).
- `pipeline/crop.py` re-crops the ETA PDFs; it needs page renders that are not committed: for each PDF run `pdftotext -bbox` -> `eta/<t>/bbox.html` and `pdftoppm -r 144 -png` -> `eta/<t>/h-NN.png`.
- Paper-fold replays only exist when the model matches the printed figure and key; models are in `pfq/models_*.json`.
